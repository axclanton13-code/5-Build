# Indie Film Collective Website

This project is a multi-page website for the Indie Film Collective, a creative community focused on independent film screenings, workshops, and collaboration opportunities. The site uses CSS, mobile first design, relative navigation links, and meaningful image alt text.

## Pages Included

- Home: `index.html`
- Film Screenings: `screenings.html`
- Workshops: `workshops.html`
- Collaborations: `collaborations.html`
